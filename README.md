
# Space-Janitors

## 프로젝트 소개

**Space-Janitors**는 우주 공간을 배경으로 한 청소 및 탐험 게임 프로젝트입니다.

플레이어는 우주 청소부가 되어 다양한 구역을 탐험하고,
주어진 임무를 수행하며 우주 환경을 정리하는 것을 목표로 합니다.

본 프로젝트는 게임 개발 과정에서 다양한 프로그래밍 기술과
게임 시스템 구현 방법을 학습하고 적용하기 위해 제작되었습니다.

## 게임 콘셉트

Space-Janitors는 우주 청소부라는 독특한 소재를 활용한 게임입니다.

플레이어는 우주 환경에서 여러 임무를 수행하며
게임 속에서 다양한 상황을 경험할 수 있습니다.

### 핵심 콘셉트

- 우주 공간을 배경으로 한 게임 환경
- 우주 청소부라는 독창적인 캐릭터 설정
- 탐험과 임무 수행 중심의 게임 구성
- 플레이어의 조작에 따른 상호작용
- 게임 진행에 따른 목표 달성

※ 실제 게임에 구현된 요소에 맞게 수정할 수 있습니다.

## 🕹️ 게임 플레이

### 1. 게임 시작

플레이어는 게임을 실행한 후 메인 화면에서 게임을 시작합니다.

### 2. 캐릭터 조작

플레이어는 캐릭터를 직접 조작하여 게임 공간을 이동합니다.

### 3. 환경 탐험

게임 내 다양한 공간을 이동하며 임무에 필요한 요소를 탐색합니다.

### 4. 임무 수행

게임에서 주어진 목표를 확인하고 해당 임무를 수행합니다.

### 5. 목표 달성

정해진 조건을 만족하면 임무를 완료합니다.

※ 위 과정은 기본적인 게임 흐름 예시입니다.

## 📂 프로젝트 구조

아래는 게임 프로젝트의 일반적인 폴더 구조 예시입니다.
실제 프로젝트 구조에 맞게 변경해 주세요.

```text
Space-Janitors/
├── Assets/
│   ├── Scripts/
│   ├── Scenes/
│   ├── Prefabs/
│   ├── Materials/
│   ├── Textures/
│   ├── Animations/
│   ├── Audio/
│   └── UI/
├── README.md
└── .gitignore
```

### 폴더 설명

- **Scripts** : 게임 로직을 구현하는 스크립트
- **Scenes** : 게임 화면 및 스테이지
- **Prefabs** : 재사용 가능한 게임 오브젝트
- **Materials** : 오브젝트의 재질
- **Textures** : 캐릭터 및 환경 텍스처
- **Animations** : 캐릭터와 오브젝트의 애니메이션
- **Audio** : 배경 음악 및 효과음
- **UI** : 게임 인터페이스 관련 리소스
