# KESTREL-07 — 우주선 청소부들용 정비선

Fenris Frigate의 공개 상품 이미지에서 길쭉한 선체, 층을 이룬 외장판, 돌출된 조종실 등 하드서피스 표현을 참고하여 새로 제작한 우주선입니다. 원본 모델·텍스처·코드·소리 파일을 사용하지 않았습니다. 원본 상품과 동일한 그래픽 품질이나 동일한 구조를 재현한 제품은 아닙니다.

## 에셋과 실행 버전

- `Prefabs/Kestrel07_Complete.prefab`: 선체·실내·가구·정비 소품. 일부 상자와 수리 패널에 테스트용 스크립트가 있으므로 단독 아트로 쓸 때는 해당 스크립트와 Rigidbody를 제거하거나 비활성화하세요.
- `Scenes/Kestrel_FirstPerson.unity`: 플레이어·HUD·수거함·쓰레기·별 배경까지 들어간 1인칭 테스트 씬.
- 재질과 메시 원본은 `Materials`, `Meshes`, `Shaders`에 있습니다. 편집용 생성기는 전체 프로젝트의 `Assets/Editor/BuildFrigate.cs`, `FrigateGeometry.cs`에 있습니다.
- Unity 6000.5.10f1 / Built-in Render Pipeline. URP/HDRP 변환은 하지 않았습니다. 전용 셰이더가 있어 단순한 자동 재질 변환만으로 같게 보이지 않을 수 있습니다.

## 구조

선체는 약 81 m 길이이며 엔진과 정비 발판을 포함합니다. 주 갑판(y=0), 하부 화물 갑판(y=-4.5), 상부 조종실(y=4.5)을 실제 계단으로 연결했습니다. 계단의 물리 충돌면은 이동을 안정화하기 위한 완만한 경사면입니다.

주 갑판에는 화물실, 기관실, 재활용실, 작업실, 의무실, 승무원실이 있습니다. 중앙 복도의 뒤쪽 계단은 하부 화물칸으로, 앞쪽 계단은 조종실로 연결됩니다. 작업실의 우측 통로가 외부 에어록입니다.

선체·엔진·배관·문틀·패널·침상·사물함·계기판을 새로 모델링했습니다. 금속 표면의 미세 변화는 전용 셰이더로 표현합니다. 발광 표시와 유리, 벽에 가려지는 표지판도 전용 셰이더를 사용합니다. 외벽 패널과 벽체, 통로, 계단에는 충돌체를 배치했습니다. 작은 장식 부품까지 모두 물리 충돌하는 것은 아닙니다.

성능을 위해 정적 메시를 구역/재질별로 합쳤습니다. 원래 부품의 계층과 충돌체는 남겨두되 일부 부품의 MeshRenderer/MeshFilter를 제거한 상태입니다. 개별 부품 형태를 다시 조정하려면 생성기를 수정하고 재생성하거나, 보관된 개별 메시를 새 오브젝트에 연결하세요. 움직이는 상자와 상호작용 패널은 합치지 않았습니다.

## 플레이

WASD 이동 / 마우스 시점 / Shift 가속 / Space 점프 또는 외부 상승 / Ctrl 외부 하강.
좌클릭 유지 잡기 / 버튼 떼기 놓기 / E 밀기 / F 유지 수리 / F 안전줄 / L 손전등.
R 복귀 / F2 에어록 / F3 안전줄 연결 후 외부 / Esc 메뉴.

쓰레기 5개를 주황색 수거함에 넣고, 작업실과 우측 외벽의 수리 패널 2개를 복구합니다. 멀티플레이·상점·산소·폭발·음성채팅·진행 저장은 없습니다. 안전줄은 18 m 거리 제한 방식으로, 선체를 감는 물리 로프는 아닙니다. 캐릭터는 이전 프로토타입을 그대로 사용합니다.
