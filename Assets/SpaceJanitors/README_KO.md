# 우주선 청소부들 — 첫 번째 3D 아트 팩

직접 제작한 원본 프로시저럴 3D 에셋입니다. 귀여운 작업복과 큼직한 부품, 투박한 작업용 우주선의 형태를 확인하는 **초기 프로토타입**입니다. 외부 구매 에셋이나 PEAK 모델을 사용하지 않았습니다.

## 사용 방법

Unity에서 `Assets > Import Package > Custom Package`로 `SpaceJanitors_StarterArt.unitypackage`를 가져옵니다. `Assets/SpaceJanitors/Prefabs`의 프리팹을 씬에 배치하면 됩니다. 제작 및 검수 환경은 Unity 6000.5.10f1, Built-in Render Pipeline입니다. URP/HDRP용 재질 변환은 포함하지 않았습니다. 해당 파이프라인에서는 재질 변환이 필요합니다.

전체 제작 프로젝트 `SpaceJanitorsArt`를 Unity Hub에서 열어도 됩니다. `Scenes/ArtShowcase.unity`는 배치 확인용 씬이며 플레이 가능한 게임은 아닙니다. Scene 뷰에서 우주선 선택 후 F 키로 위치를 맞추세요.

## 구성

- 캐릭터 4종: 주황, 민트, 노랑, 분홍. 외형과 크기는 같고 색상만 다릅니다. 직업이나 능력 차이는 없습니다.
- 우주선 1종: 약 33 × 45 m의 외형, 단층 작업 구역 6개와 중앙 복도, 우측 에어록, 외부 정비 발판, 엔진, 안테나, 수리 패널.
- 소품 3종: 화물 상자, 미션 컴퓨터, 수리 패널.
- 공유 재질, 모서리를 다듬은 메시, 우주선의 정적 충돌체.

캐릭터는 약 2.08 m, 발바닥을 원점으로 하며 +Z 방향을 바라봅니다. 머리·팔·다리는 분리된 계층으로 제공합니다. 스킨 메시, 휴머노이드 리깅, 애니메이션, 이동 컨트롤러 및 캐릭터 충돌체는 포함하지 않았습니다. 실제 게임에 넣을 때 애니메이션 방식에 맞게 리깅 또는 부위별 움직임을 연결해야 합니다.

## 우주선 구조

`Interior` 아래에 Cargo / Cooling / Waste / Workshop / LifeSupport / Bridge가 있습니다. `Exterior/Roof`를 비활성화하면 내부를 볼 수 있습니다. 중앙 복도는 약 3.85 m, 방 출입구는 약 3 m입니다. 외부 벽의 실제 구멍을 통해 에어록으로 이동하도록 구성했습니다. 에어록 문짝은 열린 상태이며 별도 오브젝트로 분리했습니다.

`GameplayAnchors`에는 생성 위치, 임무 위치, 안전줄 연결 위치, 외부 수리 위치를 빈 오브젝트로 표시했습니다. 이는 개발용 위치 표시이며 상호작용 기능은 없습니다. 밖에서 이동하려면 향후 무중력 이동·안전줄·잡기 시스템을 붙여야 합니다. 외부 원통 장식의 일부는 기본 캡슐 충돌체를 사용하므로 정밀한 물리 작업 전에 조정해야 합니다.

## 이번 버전의 범위

실내·외를 가진 실제 3D 메시와 프리팹을 제공합니다. 임무, 네트워크, 중력, 안전줄, 수리, 폭발, 산소, 에어록 기압, 캐릭터 애니메이션은 구현하지 않았습니다. 표면의 낡은 질감을 위한 텍스처와 LOD, 렌더링 배칭 최적화도 후속 작업입니다. 프리팹은 편집하기 쉽도록 여러 부품으로 구성했습니다.

10~20분은 플레이 목표입니다. 모델 크기만으로 플레이 시간을 보장할 수 없으므로 이동 속도·임무 개수·인원수에 따른 검증이 필요합니다.

## 검수

Unity에서 생성·스크립트 컴파일·프리팹 저장·렌더링·패키지 내보내기를 확인합니다. 생성 메시의 잘못된 좌표와 면, 필수 위치 표시를 검사한 결과는 배포 폴더의 `Validation.txt`에 기록합니다. 별도 재실행 검사 결과는 `Recheck.txt`에 기록합니다. 실제 멀티플레이 및 캐릭터 이동 테스트를 대체하지 않습니다.
